ADR-001 — Contexte : 25 heures, groupe de 3 à 4 étudiants, PHP 8 + MySQL/MariaDB, poste local sans Composer.  
Décision : monolithe modulaire en couches public → Controllers → Services → Repositories → PDO.  
Justification : aucun temps d'apprentissage d'un framework, dépendances maîtrisées, déploiement local simple.  
Conséquences : routage et tests écrits à la main ; SQL limité aux Repositories ; secrets dans .env non versionné.  
Statut : acceptée en séance 4.
